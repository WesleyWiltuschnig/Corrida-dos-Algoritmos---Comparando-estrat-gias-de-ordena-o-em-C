BS

Bubble Sort

Melhor: O(n) Pior: O(n²) Médio: O(n²)
Compara pares de elementos adjacentes e os troca se estiverem fora de ordem. Repete essa varredura até que nenhuma troca seja necessária. Os valores maiores "sobem" gradualmente para o final — como bolhas de ar na água.
💡 Analogia: bolhas subindo num copo — as maiores chegam ao topo mais rápido. Com a flag de otimização, se uma passagem inteira não fez nenhuma troca, o algoritmo para. Isso o torna O(n) em listas já ordenadas.

SS

Selection Sort

Melhor: O(n²) Pior: O(n²) Trocas: ≤ n−1
A cada rodada, varre todo o trecho não-ordenado para encontrar o menor elemento e o coloca na posição correta com uma única troca. Não aproveita a ordem existente, mas garante o mínimo possível de movimentações físicas de dados.
💡 Analogia: você tem 10 cartas embaralhadas. Olha todas, pega a menor, coloca na pilha. Olha as restantes, pega a menor, coloca. Repete — sempre olha tudo antes de mover.

💾
Memória Flash / SSD
Cada célula flash suporta número limitado de escritas. Minimizar trocas aumenta a vida útil do dispositivo.
🗄️
Banco de dados em disco lento
Mover registros grandes em disco é muito mais caro que comparar. Poucas trocas = menos I/O = mais velocidade.
🏆
Seleção de candidatos
Lógica de RH: varre todos os currículos, seleciona o melhor, contrata. Varre os restantes, seleciona o próximo.
🃏
Ordenar cartas na mão
Humanos naturalmente usam Selection Sort com cartas físicas — olham tudo, pegam a menor, colocam na pilha ordenada.
IS

Insertion Sort

Melhor: O(n) Pior: O(n²) Adaptativo
Pega um elemento de cada vez e o insere na posição correta dentro da parte já ordenada. Para de comparar assim que encontra um elemento menor — o que o torna adaptativo: quanto mais ordenada a lista, menos trabalho ele faz.
💡 Analogia: ordenar cartas no baralho. Você pega uma carta nova e a desliza da direita para a esquerda até achar o lugar certo. Se a mão já estiver ordenada, nenhuma carta se move.

🐍
Python — Timsort
O Python usa Timsort internamente, que usa Insertion Sort para blocos pequenos. Toda chamada a sorted() usa isso.
📊
Dados de streaming
Sensores IoT, dados de bolsa e logs chegam em ordem aproximada. Insertion Sort os mantém ordenados com custo mínimo.
🗃️
Banco de dados OLTP
Novos registros chegam constantemente. Insertion Sort insere cada novo item no lugar certo em tempo quase linear.
🏅
Placar em tempo real
Quando poucos jogadores mudam de posição, Insertion Sort atualiza o ranking quase instantaneamente.
